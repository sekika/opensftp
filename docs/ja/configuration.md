## 画面の調整と設定の保存 {#画面の調整と設定の保存}

### パネルとバー

フォルダ一覧・キュー・ログの間の区切り線を上下にドラッグすると、高さを調整できます。キューやログを非表示にすると、表示中のパネルが空いた領域を使います。

表示メニューから、次の領域を個別に表示・非表示にできます。

| メニュー | 対象 | 次回起動時 |
|---|---|---|
| 接続バーを表示 | 最上部のOpenSFTP、接続先入力、候補選択、接続ボタン。 | 必ず表示します。 |
| 全体のステータスバーを表示 | 最下部の接続先・実行状態・中断・キュー・ログのボタン。 | 前回の状態を復元します。 |
| フォルダのステータスバーを表示 | 一覧下部の項目数、選択件数、ドラッグ操作の案内。 | 前回の状態を復元します。 |
| 転送・操作キューを表示 | 処理の一覧と結果。 | 前回の状態を復元します。 |
| 実行ログを表示 | 選択した処理のログ。 | 前回の状態を復元します。 |

初回は接続バー・両ステータスバー・キューを表示し、ログは非表示です。バーを隠しても、表示メニューから再び表示できます。

### 言語

表示は日本語と英語に対応します。起動時はシステムの優先言語が日本語なら日本語、それ以外なら英語になります。「言語 / Language」メニューの「日本語」「English」で、再起動せずに変更できます。次回起動時は再びシステム言語から選びます。

本書のメニュー名は日本語表示に合わせています。画面が英語の場合は「Language → 日本語」で切り替えてください。ファイル名・パス・生ログは翻訳しません。

### 処理の上限

「設定 → 上限」に、一覧・フォルダ処理・ログ・差分・プレビューの制限をまとめています。各項目に単位と初期値を表示し、「初期値に戻す」でプレビューのページ行数・バイナリ取得量も含めて戻せます。従来のプレビュー設定値は引き継ぎます。接続タイムアウトとKeepAliveは「設定 → rsync」にあります。

| 分類 | 項目 | 初期値 | 上限超過時の動作 |
|---|---|---|---|
| ファイル一覧 | 1フォルダの最大項目数 | 100,000件 | 一覧全体を無効にし、その一覧を使う転送・削除も中止。 |
| ファイル一覧 | 一覧の最大取得量 | 64 MiB | 一覧取得を中止。不完全な一覧は使用しません。 |
| フォルダ処理 | 再帰走査の最大総項目数 | 1,000,000件 | 転送・削除を始める前の計画を中止。 |
| フォルダ処理 | 最大階層数 | 128階層 | 転送・削除を始める前の計画を中止。選択したルートを第1階層として数えます。 |
| ログ・差分 | ログの最大保持量 | 4 MiB | 各ジョブの標準出力・標準エラーごとに先頭を保持し、以降を省略。処理と進捗表示は継続。 |
| ログ・差分 | 差分の最大取得量 | 8 MiB | 差分比較を中止し、省略したことを記録。ダウンロード済みファイルは保持。 |
| プレビュー | ページ行数 | 50行 | ページを分けて表示。 |
| プレビュー | テキスト・抽出情報の最大取得量 | 1 MiB | 表示を中止。テキストはページ送り判定用の次の1行も含めて確認。 |
| プレビュー | 画像・動画の最大取得量 | 5 MiB | 元画像または動画の代表フレームの取得量が超過すると表示を中止。 |
| プレビュー | コマンドごとの処理時間 | 30秒 | コマンドを停止して表示を中止。 |

総項目数は、選択したルート1件に加え、計画のために転送元・転送先または削除対象で一覧走査した項目を数えます。スキップする項目も含み、同じフォルダの再確認用の一覧取得は加算しません。総項目数と階層数は、SFTPのフォルダ転送・再帰削除・リモート間コピーに適用し、rsync自身の走査には適用しません。一覧取得量は受信データの量で、解析後のメモリ使用量そのものではありません。SFTPプロトコルの個別パケットの検証上限とHexDumpの256 Bは固定です。

ログの保持量と差分の取得量は別々の上限です。差分を取得できても、ログの保持量を超えた部分は表示されません。履歴全体の合計サイズを制限する設定ではありません。不要な履歴はキューから削除してください。

### 保存するもの・保存しないもの

| 項目 | 起動時の動作 |
|---|---|
| 接続先の入力値 | 復元します。接続は開始しません。 |
| 一覧／アイコン表示、一覧の列幅、隠しファイルの表示 | 前回の設定を復元します。 |
| 並べ替えの項目（名前・種類・サイズ・更新時刻）と昇順／降順 | 前回の設定を復元します。初回は名前の昇順です。 |
| キュー・ログ・両ステータスバーの表示状態 | 前回の設定を復元します。 |
| ウィンドウのサイズ | 最後に閉じたウィンドウのサイズ（アプリ終了時は前面のブラウザのサイズ）を復元します。初回は1050×760ポイント、最小サイズの初期値は600×550ポイントです。 |
| ダブルクリック時の動作、ダウンロード先 | 前回の設定を復元します。 |
| 「設定 → 上限」の設定（一覧・フォルダ処理・ログ・差分・プレビュー）、プレビューウィンドウの位置・大きさ | 前回の設定を復元します。 |
| 「設定 → 外観」の設定（配色・最小ウィンドウサイズ・アイコン表示） | 前回の設定を復元します。 |
| 「設定 → rsync」の設定（rsyncの転送オプション・SSH接続の設定） | 前回の設定を復元します。 |
| 接続バーの表示、表示言語 | 上記の起動時の規則で決まります。 |
| 接続状態、表示中のフォルダ、移動履歴、選択、処理の履歴、ログの内容 | 保存しません。 |

## 利用上の制限 {#利用上の制限}

- アプリは既存のOpenSSH設定、ssh-agent、Keychain連携を利用します。鍵の作成・サーバーへの登録・パスワード管理は行いません。
- 通常ファイル・フォルダ・シンボリックリンクを対象とします。その他の特殊ファイルは転送対象外です。
- SFTPのフォルダ転送・リモート間コピー・フォルダの再帰削除は、「設定 → 上限」の最大階層数（初期128）と最大総項目数に従います。リンク名が曖昧で安全に照合できない場合も中止します。rsyncの走査にはこの階層・総項目数の制限を適用しません。
- 転送元・転送先を別のアプリや利用者が同時に変更した場合、競合を完全には検出できません。転送全体を元に戻す機能もありません。
