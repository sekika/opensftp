## ファイルを探す・開く {#ファイルを探す開く}

### フォルダを移動する

- フォルダをダブルクリックするか、一つ選択してReturnを押すと開きます。
- 上向きの矢印、または `⌘↑` で親フォルダへ移動します。
- 「戻る」「進む」の矢印、または `⌘[`／`⌘]` で移動履歴をたどれます。
- 「再読込」、または `⌘R` で現在の一覧を取得し直します。

移動に失敗した場合は、元の一覧と移動履歴を維持します。移動履歴は再接続時にリセットされ、アプリ終了後には残りません。

### 選択・表示・並べ替え

`⌘` を押しながらクリックすると選択を追加・解除でき、Shiftクリックで範囲を選択できます。一覧にフォーカスがある状態で `⌘A` を押すと、表示中の全項目を選択します。矢印キーで移動し、Shiftと矢印キーで範囲を選択することもできます。

リスト／アイコンの切替ボタン、または「表示 → アイコン表示」で表示方式を変更できます。一覧表示では、列見出しをクリックすると名前・種類・サイズ・更新時刻で並べ替えられます。同じ見出しを再度クリックすると昇順・降順が切り替わります。

通常ファイルは、PDF・画像・Office文書・圧縮ファイルなど、拡張子に対応するmacOSのアイコンを表示します。一覧表示・アイコン表示の両方に対応し、アイコンはMacにインストールされたアプリによって異なる場合があります。

「種類」欄と「情報」には、拡張子から取得したmacOSの種類名を表示します。「種類」での並べ替えもこの名前を使います。種類名の言語はmacOSの設定に従います。拡張子がない場合や種類が未登録の場合は「ファイル」と表示します。ファイル内容や拡張属性の取得は行いません。

シンボリックリンクの「情報」では、SFTPでリンク先を取得し、「オリジナル」にパスを表示します。相対パスのリンク先にはリンクが置かれたフォルダのパスを補います。取得できない場合も、その他の情報は表示します。

「情報」は、ファイル名と、種類・サイズ・ホスト・場所（項目のフルパス）・更新日・所有者・アクセス権を項目ごとに表示します。所有者はサーバーの一覧応答に従い、ユーザー名または数値IDを表示します。

「名前」「種類」「サイズ」の右側の見出し境界を左右にドラッグすると、列幅を変更できます。幅の合計がウィンドウ幅を超える場合は、横スクロールしてください。表示方式と列幅は保存され、次回起動時やアイコン表示から一覧表示へ戻したときにも復元されます。

### 隠しファイル

目のボタン、「表示 → 隠しファイルを表示」、または `⌘⇧.` で切り替えます。名前が `.` で始まる項目が対象です。初回は非表示で、その後は前回の設定を復元します。`.` と `..` は表示しません。

隠しファイルを非表示にすると、その項目の選択も解除されます。フォルダ下部の項目数は、現在表示している項目の数です。配下のフォルダまで数えた合計ではありません。

### ファイルを開く

「設定 → 操作」でダブルクリック時の動作を選べます。Returnと右クリックの「開く」も同じ設定に従います。

| 設定 | 動作 |
|---|---|
| プレビュー（初期設定） | アプリ内で読み取り専用の[プレビュー]({{ '/ja/preview/' | relative_url }}#ファイルをプレビューする)を表示します。SSH経由のコマンド実行が必要です。 |
| ダウンロードして開く | 設定したダウンロード先（初期値は `~/Downloads`）へ保存してから、Macの既定のアプリで開きます。 |

SFTP専用サーバーを利用する場合は、「ダウンロードして開く」を選んでください。ダウンロード先に同名の項目がある場合は、「上書き保存」「番号を付けて保存」「キャンセル」から選びます。

「ダウンロードして開く」で開いたファイルは、Mac側に保存したコピーです。編集して保存しても、サーバーには自動で反映されません。サーバーのファイルを更新するには、保存したファイルをアップロードします。

フォルダへのシンボリックリンクはフォルダアイコンに、ファイルへのリンクはリンク先の拡張子に応じたファイルアイコンに、それぞれリンクの矢印を重ねて表示します。リンク先を確認できない場合は一般のリンクアイコンを表示します。

シンボリックリンクを開くときは、リンク先の種類を確認します。フォルダなら移動し、ファイルならリンク先のファイルを開きます。「プレビュー」「ダウンロードして開く」の設定に従います。リンク切れや種類を確認できない場合は、説明を表示して元の一覧を維持します。

## サーバー上のファイルを管理する {#サーバー上のファイルを管理する}

| 操作 | 手順 |
|---|---|
| フォルダ作成 | フォルダ作成ボタン、または「リモート → フォルダ作成…」で名前を入力します。 |
| 名前変更 | 一項目を選び、右クリックまたは「リモート → 名前変更・移動…」で新しい名前を入力します。 |
| 別の場所へ移動 | 同じ「名前変更・移動…」で、移動先の絶対パスを入力します。 |
| 削除 | 項目を選び、削除ボタン、右クリック、または「リモート → 削除…」を選びます。 |
| 情報表示 | 項目を選び、右クリックの「情報を見る」を選びます。 |

**削除はごみ箱へ移動する操作ではなく、元に戻せません。** 確認画面には接続先と対象の完全なパスを表示します。中身のあるフォルダを削除すると、隠しファイルとサブフォルダもすべて対象になります。サーバーのルートフォルダ `/` は削除できません。

削除の途中で通信切断・権限エラー・対象の変更などが起きると、その場で停止します。すでに削除したものは戻りません。フォルダ内の一覧やリンク名を確認できない場合、または階層が深すぎる場合は、削除を開始せずに失敗します。

## キーボード操作 {#キーボード操作}

`⌘` はCommand、`⇧` はShiftです。一覧の選択・移動の操作は、一覧にフォーカスがあるときに使えます。

| キー | 操作 |
|---|---|
| Return | 接続先欄では接続、一覧では選択項目を開く。 |
| スペース | 一覧で通常ファイル、または通常ファイルへのリンクを一つ選び、リンク先の内容をプレビュー。 |
| Escape | プレビューにフォーカスがあるとき、プレビューを閉じる。 |
| 矢印キー | 項目を選択して移動。 |
| Shift＋矢印キー | 範囲を選択。 |
| `⌘N` | 新規ウィンドウを開く。 |
| `⌘A` | 表示中の全項目を選択。 |
| `⌘↑` | 親フォルダへ移動。 |
| `⌘[`／`⌘]` | 戻る／進む。 |
| `⌘R` | 一覧を再読込。 |
| `⌘⇧N` | フォルダ作成。 |
| `⌘Delete` | 選択項目を削除。確認画面を表示します。 |
| `⌘⇧.` | 隠しファイルの表示を切替。 |
| `⌘⇧K` | キューの表示を切替。 |
| `⌘⇧L` | ログの表示を切替。 |
